Software / AI

Spectrace AI

Problem and role. I built a public requirements traceability tool to explore how much rigor an AI-backed workflow needs. Strict models and repository boundaries keep invalid data from leaking through; bounded traversal, deterministic fixtures, automated tests, and Docker keep results explainable and setup repeatable.

Scope. The project uses a synthetic satellite-terminal dataset and supports read-only traceability, relationship analysis, lexical, semantic, and graph search, plus a checked-in evaluation. It does not claim deployment or outside users.
