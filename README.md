# Alexander Niejadlik | Personal Portfolio ⚡️

Welcome to the repository for my personal portfolio website! This site serves as an interactive resume and a showcase of my projects, experience, and technical skills. 

You can view the live website here: [https://alexandernjk.github.io](https://alexandernjk.github.io)

## 📋 Features

* **Fully Responsive:** Designed to look great on desktops, tablets, and mobile devices.
* **Dynamic Typing Animation:** Uses `Typed.js` for an eye-catching hero section.
* **Modern UI:** Built using the Materialize CSS framework for a clean, Google Material Design look.
* **Comprehensive Sections:** Includes detailed areas for Experience, Education, Projects, Skills, and a downloadable Resume.

## 🛠️ Technologies Used

* **HTML5 & CSS3**
* **JavaScript**
* **Materialize CSS** (Framework)
* **Typed.js** (Animation Library)
* **GitHub Pages** (Hosting)
